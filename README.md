# Voice-Driven Pomodoro Timer

キーボードをほぼ使用せず、**「音声入力とAIエージェントへの指示（Voice Driven Development）」** のみで構築された、完全オリジナルのポモドーロタイマーアプリです。

## v2（2026-09-29 リデザイン）

`frontend-design`（Anthropic公式スキル）と自作の `design_system` スキルを使って、見た目と操作を作り直したバージョンです。機能（集中／休憩の切り替え、時間の設定、環境音、円／バーの表示）はv1と同じです。

- **主役は「お皿」ひとつ**：TIME TIMER風の緑の扇形が、時間とともになめらかに減っていく。周りの飾りは置かないシンプルな円。
- **砂時計の表示**：円・バーに加えて3つ目の表示。上から下へ砂が落ち、落ちている砂の筋も見える。集中と休憩が切り替わる時に砂時計が180度回転して、また砂が落ち始める（動きを減らす設定の時は回転しない）。
- **空の表示**：4つ目の表示。集中中は太陽が左の地平線から昇り、半円を描いて右の地平線に沈む（背景は雲のある昼の空）。休憩中は三日月が同じように進む（背景は星空）。昼と夜は1.5秒かけて切り替わる。色はdesign_systemのパレット内で表現（昼＝セージの空＋白い雲、夜＝こげ茶からセージのグラデーション＋白い星）。
- **植物・ろうそく・コーヒー・本の表示**（2026-09-30 追加。ボールとドラムの表示は作ってから削除）：どれも集中は緑系、休憩は茶系。
  - 植物：集中＝芽が伸びて葉が8枚まで増え、最後に花が咲く／休憩＝花束になって、少しずつ誰かの元へ運ばれ、休憩の終わりに手渡されてハートが浮かぶ（枯らさず、ハッピーエンドに）
  - ろうそく：集中＝火がゆらぎながら短くなる／休憩＝火が消えて、煙が細くなって消える
  - コーヒー：集中＝ドリッパーからしずくが落ちてカップにたまる／休憩＝湯気を立てながら減っていく
  - 本：集中＝設定時間の1/20ごとにページが1枚めくれ、右の束が薄くなる／休憩＝本を閉じて、しおりが揺れる
  - 表示が8つになったので、切り替えボタンは入りきらない幅では横にスクロールする
- **設定を一文に**：「25分集中して、5分休む」の数字をそのまま書き換えられる。
- **色は design_system の7色のみ**：集中はセージグリーン、休憩はサンド。白いカードと影で囲むのをやめ、クリーム色のテーブルに直接お皿を置いた。
- **使いやすさ**：スペースキーでスタート／一時停止、タブのタイトルに残り時間を表示、表示の切り替え（円／バー）を記憶、キーボード操作時の枠線、動きを減らす設定への対応、スマホ幅でのボタン配置。
- **滑らかな動き**：円の扇形は1秒ごとに段差で減るのではなく、なめらかに回る。バーは分数に関係なく常に20本で、1本＝設定時間の1/20（5分なら15秒、10分なら30秒）。右から左へ消えていき、使っている最中の1本がなめらかに縮む。タイマーは「終了予定時刻」から残りを計算するので、裏のタブでもずれない。
- **ホーム画面に追加できる（PWA）**：iPhoneはSafariの共有ボタン →「ホーム画面に追加」、Android/PCのChromeはアドレスバーのインストールボタンから。アプリのように全画面で開き、一度開けばオフラインでも起動できる。
- **文言**：「リセット」→「最初から」、「すぐ休憩に入る」→「休憩に入る」／「集中に戻る」、一時停止後は「再開」。

## 概要

作業（Focus）と休憩（Break）のサイクルを管理するためのシンプルなWebアプリケーションです。
TIME TIMERに着想を得た直感的なビジュアルタイマーと、集中とリラックスを切り替える環境音（Web Audio APIによる自動生成）を備えています。

## 主な機能

- **ビジュアルタイマー (TIME TIMERスタイル)**
  - 赤い円が時計回りに「白（背景色）」で上書きされていくことで、残り時間を直感的に把握可能。
- **環境音の自動生成（Web Audio API）**
  - **作業中**: 集中力を高めるブラウンノイズ/ホワイトノイズ。
  - **休憩中**: リラックスを促す森林の環境音（低音のピンクノイズ＋ランダムな小鳥のさえずり）。
  - **クロスフェード**: タイマー切り替え時に音声が急に途切れることなく、2秒間かけて滑らかにフェードアウト・フェードインします。
- **レスポンシブデザイン**
  - スマホやタブレットでも崩れない、美しくシンプルなUI。
- **完全ローカル動作・軽量**
  - フレームワーク（React等）を一切使用せず、Vanilla JS（純粋なJavaScript）とHTML/CSSのみで構築。

## 技術スタック

- HTML5
- CSS3 (CSS Variables, Flexbox, Media Queries)
- Vanilla JavaScript
- Web Audio API (ノイズ生成、オシレーター、GainNode操作)

## 開発の背景（Voice Driven Development）

このアプリは、エンジニアリングの新しい可能性を探るため、**「コードを手打ちせず、AIとの音声会話のみで要件定義から実装、バグ修正、デプロイまでを行う」** というコンセプトで開発されました。
