# Voice-Driven Pomodoro Timer

キーボードをほぼ使用せず、**「音声入力とAIエージェントへの指示（Voice Driven Development）」** のみで構築された、完全オリジナルのポモドーロタイマーアプリです。

## 概要

作業（Focus）と休憩（Break）のサイクルを管理するためのシンプルなWebアプリケーションです。
TIME TIMERに着想を得た直感的なビジュアルタイマーと、集中とリラックスを切り替える環境音（Web Audio APIによる自動生成）を備えています。

## 主な機能

- **ビジュアルタイマー (TIME TIMERスタイル)**
  - 赤い円が時計回りに「白（背景色）」で上書きされていくことで、残り時間を直感的に把握可能。
- **環境音の自動生成（Web Audio API）**
  - **作業中**: 集中力を高めるブラウンノイズ/ホワイトノイズ。
  - **休憩中**: リラックスを促す森林の環境音（低音のピンクノイズ＋ランダムな小鳥のさえずり）。
  - **クロスフェード**: タイマー切り替え時に音声が急に途切れることなく、2秒間かけて滑らかにフェードアウト・フェードインします。
- **レスポンシブデザイン**
  - スマホやタブレットでも崩れない、美しくシンプルなUI。
- **完全ローカル動作・軽量**
  - フレームワーク（React等）を一切使用せず、Vanilla JS（純粋なJavaScript）とHTML/CSSのみで構築。

## 技術スタック

- HTML5
- CSS3 (CSS Variables, Flexbox, Media Queries)
- Vanilla JavaScript
- Web Audio API (ノイズ生成、オシレーター、GainNode操作)

## 開発の背景（Voice Driven Development）

このアプリは、エンジニアリングの新しい可能性を探るため、**「コードを手打ちせず、AIとの音声会話のみで要件定義から実装、バグ修正、デプロイまでを行う」** というコンセプトで開発されました。
